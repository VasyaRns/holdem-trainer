# Тренажёр холдема

Интерфейс по-русски. Шапка приложения: «Тренажёр холдема».

## Карта

- `packages/domain` — спот, квоты, тексты справочника и терминов, интерфейс `SolutionSource`.
- `packages/engine` — чистые функции и модули тренажёров. Без React, без базы и без чтения файла чартов.
- `client` — экраны в `client/src/features`. Общие кнопки в `client/src/components`.
- `server` — Fastify, Prisma и первая реализация `SolutionSource` по `CHARTS_PATH`.
- `packages/solver` — позже, только для API. В первой версии пакета нет.

## Тренажёр

Новый тренажёр — файл в `packages/engine/drills` и одна строка в `packages/engine/registry.ts`. Модуль отдаёт `id`, название, уровни, `generate`, `grade` и ссылку на статью. Оболочка сессии модуль не разбирает.

Строка `Answer`: `playerId`, `drillId`, `level`, JSON вопроса, JSON ответа, `correct`, время ответа. Новая колонка под тренажёр не нужна. Индекс для последних 20: `(playerId, drillId, level, createdAt)`.

У вопроса в JSON есть `handId`. Сейчас у каждого вопроса свой. Состояние сессии лежит по `sessionId`.

## Термин и статья

Это разные записи в `packages/domain`, не одно поле `text`.

Термин: `id`, `title`, `text` (одно предложение), `group`. Если есть статья, `articleId` ведёт на неё.

Статья: `id`, `what`, `example`, `caveat`. Кнопка «Тренировать» только если задан `drillId`. Иначе строка «Тренажёра пока нет».

## Чарты

Файл чартов только через `CHARTS_PATH`, только на чтение, в git и в сборку клиента не класть. API отдаёт список спотов или один спот. Движок получает уже готовую смесь и сам файл не открывает. Солвер и ICM потом — другие реализации `SolutionSource`, не новая таблица ответов.

## Проверка

Подшаги одного блока идут по порядку. Подшаг проверяется везде, куда дошло изменение: фикстура и справочник для формулы, `inject` и клиент для маршрута, тест и браузер для экрана. В браузере открыть каждый маршрут с общим компонентом или состоянием. В конце подшага `npm test` и `npm run build`.

После подшага — `/review-bugbot` по незакоммиченным изменениям, затем правка замечаний, которые меняют поведение. После последнего подшага блока закоммитить его и запушить. Чарты и `.env` не коммитить. Затем остановиться и ждать сообщение «Дальше».

## Дизайн

Принятый вид: бумажный фон, тёмный текст, один зелёный акцент. Если есть сомнение в цвете, шрифте или плотности, не менять стили. Сначала предложить три варианта с фоном, текстом, акцентом и коротким отличием и дождаться выбора.
