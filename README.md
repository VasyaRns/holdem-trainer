# Тренажёр холдема

Локальный тренажёр: счёт, диапазоны, игра «Пары» и справочник. Один профиль, без регистрации.

## Запуск

```sh
cp .env.example .env
docker compose up --build
```

В `.env` задайте `CHARTS_PATH` — путь к файлу чартов на этой машине. Compose монтирует его в API только на чтение. Файл не коммитится и не попадает в сборку клиента.

Приложение: http://127.0.0.1:8080. API: http://127.0.0.1:8787. При старте API применяет миграции. Проверка:

```sh
curl -fsS http://127.0.0.1:8787/api/health
```

Ответ `{"ok":true}` значит, что API видит Postgres.

Если `CHARTS_PATH` не задан, compose монтирует `server/test/fixtures/charts.json`. Если файла нет или он не читается, API отвечает «Чарты не подключены» и не подставляет другой диапазон.

Пароль Postgres в `.env.example` годится только для этого compose.

## Проверки

```sh
npm test
npm run build
```

Тест записи в Postgres пропускается, пока не задан `DATABASE_URL`.
