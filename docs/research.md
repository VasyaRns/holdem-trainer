# Что взято в тренажёр

Сверены форматы, у которых есть однозначный ответ: Poker Gym, Preflop+, Poker Trainer, Pot Commit, Tools of Poker, PokerChart VIP, курс SplitSuit, а также *Essential Poker Math*, *Modern Poker Theory*, *Applications of No-Limit Hold'em* и *The Grinder's Manual*.

Общий приём: один вопрос на экран, проверка сразу, одна строка формулы после ответа, мастерство отдельно по навыку. В первую версию вошли ауты, правило 2 и 4, пот-оддсы, сравнение цены колла с эквити, комбинации с блокерами, EV колла, MDF и альфа, SPR. Диапазон тренируется так: позиция и спот, случайная рука, выбрать действие. Рядом одна игра на память, «Пары»: тот же чарт, без поля ответа.

Чарты берутся из локального PokerSlover и не публикуются. API читает `CHARTS_PATH` и отдаёт список спотов или один чарт.

Рисование всей сетки 13×13 и симулятор полной раздачи в первую версию не входят.

## Приёмы из GTO-тренажёров

Берутся приёмы тренировки, не библиотеки решений.

GTO Wizard. На сложном уровне диапазонов после действия называется доля с шагом 10 процентных пунктов, зачёт при отклонении не больше 10. Верный ответ сразу открывает следующий вопрос, ошибка держит формулу до Enter. Сохранённый набор — позиция, стек и чарт в один клик, со своей статистикой. Клавиши есть на действия и на следующий вопрос. Вместо EV loss в больших блайндах на 100 рук пишется величина промаха: на сколько пунктов или комбо ответ уехал. Это поле в JSON ответа.

GTO Lab. Орбита: один стек, ответы по кругу позиций из чартов открытия. Сравнение стеков: одна рука на двух стеках рядом. Это экран изучения, не вопрос и не квота. Кнопка «Тренировать» в статье справочника открывает нужный уровень.

GTO Gecko. Промахнутый шаблон возвращается в той же сессии, пока не будет двух верных ответов подряд. Эти повторы идут в квоту.

## Что отложено

У каждого пункта есть место, и первая версия его не занимает так, чтобы потом пришлось ломать сессию. Каталог, квота, «Сегодня» и таблица `Answer` остаются. Новый источник ответа — другая реализация `SolutionSource`, не новая колонка ответа.

- Раздача до ривера. Сейчас у каждого вопроса свой `handId`. Следующий спот той же руки добавляется в ту же цепочку.
- Несколько столов. У стола свой `sessionId`. Сейчас на экране один.
- ICM. В споте уже есть пустые поля выплат, числа игроков до призов и стеков остальных мест. Математические тренажёры их не читают.
- Nodelock. Рядом со спотом можно будет держать замок частот. Первая версия поле не заполняет и не показывает.
- Свой солвер. Пакет `packages/solver` подключает только API. Маршрут `POST /api/solutions` сейчас отвечает сразу и позже может вернуть идентификатор задачи.
- История рук. Разбор текста даёт список спотов. Это отдельный экран, не новая форма ответа.
- ELO. Второе число из тех же строк `Answer`. Уровень по-прежнему открывает квота.
- Банк-трекер. Отдельные строки денег, не ответы тренажёра.
- Push/fold и дерево ставок. Ещё две реализации `SolutionSource`. Отдельного солвера пуша и постфлоп-дерева в этой версии нет.

В справочнике у этих тем нет кнопки «Тренировать», есть строка «Тренажёра пока нет».
